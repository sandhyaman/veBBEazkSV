# 项目简介

## 核心功能
- 用户登录注册
- 音乐推荐
- 歌曲排行
- 全部歌曲浏览
- 用户中心
- 音乐数据可视化分析
- 音乐播放
- 用户管理
- 歌曲评论管理
- 歌曲信息管理
- 歌曲分类管理
- 歌曲动态管理

## 适用场景
- 音乐爱好者
- 音乐平台
- 音乐教育机构
- 音乐研究学者

## 技术特点
- 使用Django框架进行开发
- 数据库采用MySQL
- 前端界面采用HTML、CSS和JavaScript
- 支持音乐数据可视化分析
